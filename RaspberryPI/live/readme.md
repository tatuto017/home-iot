# LIVE配信の自動保存

## Pythonモジュールのインストール
```
uv pip install TikTokLive
uv pip install streamlink
```

## モジュール一覧
| スクリプト | 機能 |
| --- | --- |
| `resync.sh` | OneDriveの再同期 |
| `showroom_fork.sh` | node-redからshowroomを起動 |
| `showroom.sh` | showroomの配信保存スクリプト |
| `tiktok_fork.sh` | node-redからtiktokを起動 |
| `tiktok.sh` | tiktokの配信保存スクリプト |
| `tiktok.py` | tiktokの配信の検出スクリプト |
